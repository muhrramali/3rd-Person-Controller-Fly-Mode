# 3rd-Person-Controller-Fly-Mode

A Unity repository maintained by **Muhrram Ali** (`muhrramali`) housing the **3rd Person Controller + Fly Mode** asset package (`Assets/3rdPerson+Fly`) for third-person character movement, flight animations, and camera control.

## Overview

- **Repository:** `3rd-Person-Controller-Fly-Mode`
- **Main Asset Folder:** `Assets/3rdPerson+Fly` (along with its `Assets/3rdPerson+Fly.meta` metadata file)
- **Role:** Provides third-person character navigation, flight movement/animations, and camera handling for Unity projects such as **Desert Oasis Caravan Stop** (CSE-411 Mini Project 1)

## Project Structure

- `Assets/3rdPerson+Fly` — Core controller, flight animation, and camera assets
- `Assets/3rdPerson+Fly.meta` — Unity asset metadata for `3rdPerson+Fly`
- `README.md` — Repository documentation
